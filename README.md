# Mel Robbins Official Website Clone

Pixel-perfect, fully responsive clone of [melrobbins.com](https://melrobbins.com) built with React, Vite, Tailwind CSS, Lucide Icons, and Framer Motion.

## 🚀 Features

- **Exact Brand Identity & Typography**: Authentic colors (Mel yellow `#FFD200`, deep black `#111111`, cream `#FAF7F2`), clean bold typography (Montserrat & Inter).
- **Top Announcement Bar**: Yellow top banner with book promotion.
- **Floating Island Header**: Signature `Mel ROBBINS` vector logo + floating white capsule navbar with dropdowns (Podcast, Topics, Books, About, Newsletter, Search).
- **Hero Section**: Full-bleed portrait of Mel Robbins, quote carousel with red TIME / Boston Globe logos, and 7 pagination dots.
- **The #1 Podcast on the Globe**: Featured podcast section with Mel's portrait and CTA.
- **Top Episodes**: 5 video/episode thumbnail cards (Ep 420, 435, 361, 274, 436).
- **Library Search & Topic Filter**: Search box + 8 category cards with yellow circular badge icons (Anxiety, Confidence, Habits, Happiness, Health, Most Popular, Motivation, Relationships).
- **The #1 Book in the World**: 3D cover of *The Let Them Theory* with sticker badges.
- **2 Million Readers Newsletter**: Card with airplane photo + golden yellow gradient subscription form.
- **Hey, it's your friend, Mel**: Photo carousel + bio copy.
- **Footer**: Multi-column site navigation, social media channels, legal links, and floating "New Here?" button.

## 🛠️ Tech Stack

- **Framework**: React 18
- **Bundler**: Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Animations**: Framer Motion
- **Language**: TypeScript

## 📦 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
